# 🐍 Python for DevOps

A collection of Python mini-projects and utility scripts created while learning Python programming, system administration, and DevOps automation.

This repository showcases my hands-on practice with Python fundamentals, API development, system utilities, and AWS S3-related scripting.

## 📂 Projects

| Project                    | Description                                                       |
| -------------------------- | ----------------------------------------------------------------- |
| `Grade_check.py`           | A Python program for checking grades based on marks.              |
| `Guess_Game.py`            | A number-guessing game to practice Python logic and conditionals. |
| `api.py`                   | A Python API project for exploring API development.               |
| `percentage_calculator.py` | A utility to calculate percentages.                               |
| `s3_utils.py`              | A utility script for working with AWS S3.                         |
| `system_utils.py`          | A script for exploring system information and utilities.          |

## 🚀 Getting Started

### Prerequisites

* Python 3 installed
* Git installed (optional, for cloning the repository)

### Clone the Repository

```bash
git clone https://github.com/Himanshu5051/Python-for-devops.git
cd Python-for-devops
```

### Run a Project

The Python files are inside the `Mini Projects` directory.

For example, to run the grade-checking script:

```bash
python "Mini Projects/Grade_check.py"
```

You can replace `Grade_check.py` with another script name to run a different project.
